# Curiosity shorts: posting kit (English)

Six 9:16 shorts, cut from the creator's own English narration. Each one raises a worry, shows a little, then stops on an open question. The end card blurs the answer and points to the exact minute of the full video.

Full video: https://youtu.be/mh1rfSrl6fA

## Every short, every time

1. **Upload** as a Short (vertical, under 60 s). Set it to Public.
2. **Related video:** in Studio, open the Short's details, then "Related video", and pick the full video. This puts a clickable link on the Short in the feed. It's the main way Short viewers reach the long video.
3. **Pinned comment:** paste the pinned comment below and pin it.
4. **Post one a day** (or every other day), not all six at once. YouTube tests each Short separately.
5. Instagram: post it as a Reel, put the YouTube link in your bio, and say "link in bio" in the caption.

Suggested order: calls → thirtyk → blocked → writeoff → salary → cibil.
